# Behavioral Profiling & Clinical Assessments

Profile Guru contains a robust assessment framework that parses direct messages and transcribes conversations to evaluate relationship dynamics, personality traits, and clinical indicators.

---

## 1. Orchestrated Assessment Pipeline

Behavioral profiles are generated by the [run_assessment()](file:///f:/Github/Profile-Guru/src/assessment/pipeline.py#L21-L85) pipeline orchestrator. It automatically routes the request to one of two pipelines based on model capabilities:

```
                          ┌───────────────────────────┐
                          │    Profile Generation     │
                          │   /api/v1/rag/.../profile │
                          └─────────────┬─────────────┘
                                        │
                                        ▼
                          ┌───────────────────────────┐
                          │   Model Size Classifier   │
                          │   (src/assessment/model)  │
                          └─────────────┬─────────────┘
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 │ (Large: Gemini / Cloud)                     │ (Small: Ollama / Local)
                 ▼                                             ▼
     ┌──────────────────────┐                      ┌──────────────────────┐
     │ Single-Pass Pipeline │                      │  Modular Sequential  │
     │                      │                      │       Pipeline       │
     │ Sends entire prompt  │                      │                      │
     │ context in one large │                      │ Step 1: Linguistic   │
     │ message token.       │                      │ Step 2: Tone         │
     └──────────────────────┘                      │ Step 3: Conflict     │
                                                   │ Step 4: Scoring      │
                                                   │ Step 5: Synthesis    │
                                                   └──────────────────────┘
```

### Single-Pass Pipeline (Large/Cloud Models)
If the active model is classified as `large` (e.g. `gemini-1.5-flash`), the system formats the raw messages, retrieved knowledge snippets, and framework guidelines into a single prompt and dispatches it.

### Modular Sequential Pipeline (Small/Local Models)
For smaller models (e.g., local Ollama `gemma-3-4b` or CPU-bound models), sending 300,000 characters causes context exhaustion. The pipeline splits the assessment into sequential sub-tasks:
1. **Linguistic Features:** Evaluates style, punctuation, and vocabulary. (Reads raw logs).
2. **Tone & Responsiveness:** Evaluates overall energy and response length. (Reads raw logs + step 1 analysis).
3. **Conflict & Regulation:** Evaluates tension handling and apologies. (Reads raw logs + steps 1 & 2 analysis).
4. **Scoring Dimensions:** Assigns scores (1-10) for each dimension based on steps 1-3. (No logs; analysis context only).
5. **Synthesis:** Builds the final markdown report using the compiled analyses.

## 2. Assessment Frameworks & Clinical Screeners

Profile Guru supports two classes of assessments:

### Class A: Psychological Traits (LLM-Synthesized)
These frameworks evaluate behavioral traits based on linguistic markers and generate formatted Markdown assessments:
- **Conversation Pattern Analysis (`communication_style`):** Examines directness, expressiveness, responsiveness, formality, and conflict style.
- **Big Five / OCEAN (`big_five`):** Assesses Openness, Conscientiousness, Extraversion, Agreeableness, and Neuroticism.
- **Attachment Style (`attachment`):** Classifies the contact into Secure, Anxious, Avoidant, or Disorganized categories.
- **Emotional Intelligence (`emotional_intelligence`):** Scores Goleman's EQ categories (Self-awareness, Self-regulation, Motivation, Empathy, Social Skills).

### Class B: Clinical Screeners (Deterministic)
Screeners are standard clinical questionnaires filled out by practitioners. Scoring is **100% deterministic** and computed in python without LLM interaction:
- **PHQ-9 (Depression Severity):** 9 questions scored 0-3. Cut-points: Minimal (0-4), Mild (5-9), Moderate (10-14), Moderately Severe (15-19), Severe (20-27).
- **GAD-7 (Anxiety Severity):** 7 questions scored 0-3. Cut-points: Minimal (0-4), Mild (5-9), Moderate (10-14), Severe (15-21).
- **BHS (Beck Hopelessness Scale):** 20 true/false questions. Cut-points: Normal (0-3), Mild (4-8), Moderate (9-14), Severe (15-20).

## 3. Storage & Versioning of Reports

Assessments are stored in the contact's directory to ensure records are preserved:

- **Versioned Folder (`chats/<contact>/assessments/`):**
  Every generation is saved with a timestamp:
  - `<framework_id>_<YYYYMMDDTHHMMSS>.md`: The markdown profile text.
  - `<framework_id>_<YYYYMMDDTHHMMSS>.json`: The metadata containing start/end months, scores dict, citations, provider, and model name.
- **Latest Cache (`chats/<contact>/`):**
  To support backward-compatible frontend queries, the files are copied atomically (using temporary files and `os.replace` to prevent corrupted writes) to:
  - `personality_assessment.md`
  - `personality_assessment.json`
- **Database Index:**
  Each generated report metadata is stored in the SQLite `assessment_history` table for quick lookup.

## 4. Programmatic PDF Compilation (`report_generator.py`)

Practitioners can export these assessments as professional PDF documents compiled via `ReportLab` and styled dynamically:
- **Matplotlib Visualizations:** Generates sentiment trend charts (line graph) and weekly volume histograms, saving them directly as flowables.
- **Table Formatting:** Formats conversation snippets in alternating light-gray tables.
- **XML Operator Safety:** Ensures raw markdown text is escaped (`xml.sax.saxutils.escape`) to prevent XML parsing crashes (such as unmatched `<` or `>` operators) inside ReportLab flowable stories.
- **Dynamic Layout:** Rearranges pages according to the practitioner's preferred template order defined in the Settings menu.
