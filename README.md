# profiler_guru (InstaSync AI)

📸 InstaSync AI: DM Analysis & Profiler

## Features
- Instagram Background Sync
- Historical Data Import
- RAG-powered Search & Query
- Psychological Profiling

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Configure environment variables in `.env`.
3. Run the app: `python main.py`

## Testing
Comprehensive tests are available in the `tests/` directory.
For detailed instructions on running and adding tests, see [Testing Documentation](tests/README.md).

To run all tests:
```bash
PYTHONPATH=. python3 -m pytest tests/
```

## Documentation Policy
This project maintains a strict synchronization between documentation and testing. Any changes to documentation should trigger a review and corresponding update to the test suite.
